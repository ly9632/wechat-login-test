# 微信登录模块测试项目

## 📌 项目简介
本项目是一个针对“微信登录及找回密码”模块的完整测试实战项目，涵盖前端环境搭建、功能测试、缺陷管理以及 UI 自动化测试。

## 🛠️ 技术栈
- 前端 Mock 环境：HTML / CSS / JavaScript
- 自动化测试：Node.js + TypeScript + Playwright
- 测试管理：Markdown (测试用例、缺陷单、回归记录)

## 🚀 如何运行自动化脚本
1. 安装依赖：`npm install`
2. 启动本地服务器：`npx serve .`
3. 运行自动化测试：`npx playwright test --headed`

## 🐞 发现的核心缺陷 (部分)
1. 密码明文状态下，眼睛图标反向且无法切换。
2. 浏览器自带密码显示按钮与自定义按钮重叠冲突。
3. Edge 浏览器强制弹出密码强度提示，阻断操作。
*(详见缺陷单文档)*

## ✅ 自动化成果
提取 3 条 P0 级核心回归用例，单次自动化回归耗时仅需 **3.6 秒**。
